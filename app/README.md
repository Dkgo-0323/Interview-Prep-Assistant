# AI 面试助手 - 前端使用指南

## 🚀 快速启动

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

复制 `.env.example` 为 `.env`，填入你的 OpenAI API Key：

```bash
OPENAI_API_KEY=your_api_key_here
```

### 3. 启动应用

```bash
streamlit run app/main.py
```

应用将在浏览器中自动打开，默认地址：`http://localhost:8501`

---

## 📖 使用流程

### 第 1 步：上传文档

1. 上传职位描述 (JD) 文件（支持 PDF/DOCX/TXT）
2. 上传个人简历文件（支持 PDF/DOCX/TXT）
3. 系统自动解析文件内容并显示预览
4. 点击「开始分析」进入下一步

### 第 2 步：查看分析报告

- **总体匹配度**：0-100 分的综合评分
- **能力雷达图**：技能/经验/学历/项目四维度可视化
- **技能对比**：已掌握 vs 缺失技能清单
- **优势与劣势**：AI 生成的核心建议

选择题目数量（10/15/20/30），点击「生成题目」

### 第 3 步：练习面试题

- 浏览 AI 生成的个性化面试题
- 点击卡片翻转查看参考答案
- 支持按类型和难度筛选题目
- 使用左右箭头切换题目

- **Apple 风格**：简洁留白、柔和圆角、微妙阴影

## 🛠️ 技术栈

- **前端框架**：Streamlit 1.40+
- **图表库**：Plotly 5.18+
- **AI 模型**：OpenAI GPT-4o-mini
- **文件解析**：pdfplumber, python-docx

---

## 📝 注意事项

1. **文件大小限制**：单个文件最大 10MB
2. **支持格式**：PDF, DOCX, TXT
3. **API 调用**：每次分析和生成题目都会调用 OpenAI API
4. **状态管理**：使用 Streamlit Session State，刷新页面会丢失数据

---

## 🐛 常见问题

### Q: 上传文件后显示解析失败？
A: 检查文件是否损坏、加密或格式不正确。建议使用标准的 PDF/DOCX 文件。

### Q: 分析过程中出现超时？
A: OpenAI API 调用超时（默认 60 秒）。检查网络连接或稍后重试。

### Q: 生成的题目数量不对？
A: 系统会根据实际情况调整题目数量，可能略少于选择的数量。

### Q: 如何重新开始？
A: 点击「重新上传」或「返回首页」按钮清空所有状态。
