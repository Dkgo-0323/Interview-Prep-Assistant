## 背景

画像后端当前返回占位内容。原页面仍提供“生成画像”入口，前端从优势数量生成带随机浮动的雷达、预设公司匹配分数，并在薪资无法解析时使用零值。这些呈现没有真实分析依据。用户希望每日只交付小而可验收的增量。

## 备选与决定

- A：入口明确说明尚未开放，提供岗位匹配分析/题库的下一步导航；不调用占位接口，不展示无依据评分/薪资。
- B：保留图表，使用固定合成数据和持续示例标识；保留视觉完整性，但增加示例流程维护。
- 用户选择 A。暂不提供独立画像能力，以可信页面边界换取较小维护成本；后续真实画像须另行讨论和验收。

## 实施与影响

画像页面改为无客户端状态的说明页，移除生成动作及结果组件的页面接入；保留既有首页、分析、题库导航。底层画像映射、历史 API 和共用图表组件暂不改动，避免扩大范围。此决定只约束画像页面入口，不代表修复了所有其他入口或实现多用户隔离。

根 README、Architecture 与开发交接同步能力边界；会话 Q-002、模型评估 Q-003 均未决。页面导航到既有分析/题库后遵循那些页面原有行为，本轮浏览器验证通过拦截 API 避免真实模型调用，不宣称验证了其外部模型效果。

## 验收、回滚与接续

执行前端 lint、类型检查和生产构建；在生产页面验证直接访问/刷新、无画像 API 请求、无生成按钮/图表、桌面/移动布局和三个导航入口。实际命令、结果、SHA 与 push 状态写入当天 daily；此文件的已确认状态不等于上述验证已完成。

后续开放画像应以真实数据契约和来源说明为前置，不直接恢复随机评分页面。若撤回本增量，使用可审阅反向改动而非共享分支 reset/强推。
