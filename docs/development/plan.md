## 风险、依赖与验证边界

- 当前实现由`api/session.py`隔离匿名访客并核对输入版本，重启/闲置失效符合本阶段选择；仍只支持单进程/单worker，不是账号、持久化或生产多实例能力。
- 本地CORS/SSE尚无完整公网代理、断连/超时/重启验收；`asyncio.to_thread`不自动终止供应商线程。
- Windows沙箱历史socketpair/Turbopack子进程通信受限；允许通信环境通过与沙箱失败分开记录，不改配置绕过错误。整个tests含外部模型调用，禁止盲跑；后端使用审阅过的`python scripts/check_backend.py`，前端`npm run check`，页面按需用合成/拦截API验收。
- 不将本地/远端、单测/真实链路、替身/真实模型、构建/部署混同。匿名隔离有本机离线/浏览器验收；真实模型质量/费用、公网部署、跨站域名Cookie/SSE代理尚未验收。
- 当前worktree仅本checkout、旧daily聊天idle、其他相关聊天notLoaded；外部编辑器/其他机器并行未知。每轮重查范围，保护用户日志/两份未跟踪分析材料/test-results及隐私，不输出.env或凭据。

## 现行工作方式（2026-10-21确认，取代历史旧规则）

**用户参与**：用户要理解主要调用链、技术取舍和常见故障，每天约10–15分钟理解进展；由助手研究/方案/拆解/实现/验证/交付。理解预算不是开发时长。不要求逐文件阅读、强制编码练习、每天prompt文档或手动分批prompt；理解题/练习可选、不作推进前置。

**每日自主推进**：一个有实质价值、可验收的功能或工程成果，允许多个相关模块/合理提交；不局限一处小修补，也不塞多个无关目标。跨天延续确认范围，按能力改善、实际验证、阶段剩余和风险衡量，不设置提交数量或每日1–3h上限。阶段目标确认后，范围内常规实现/必要修复/测试/文档/提交与现有授权分支普通推送自主完成，不每天重问A/B。

**周一集中研究**：北京时间周一尽量2–3个官方相关校招JD、1–2个优质开源项目并核查实际代码/缺口；质量优先不凑数。在journal周报回答采纳及理由、能力/缺口、路线优先级是否变化、本周交付/依赖/验收、不采纳及原因。记录直接链接/访问日、届别/类别/发布日期或未知、官方正文取得程度/在招边界、开源模块/文件/版本或SHA；区分一手、索引、推断、过期/不可访问，不捏造数据。证据不改方向则继续阶段，不堆框架服务。周二至周日只为具体问题按需查可靠资料，技术优先官方文档；周一有执行授权可继续开发。首周复用本项目旧研究并标历史，下一次周一2026-10-26更新。

**重要决策interview**：新阶段目标、重要架构/产品/数据取舍、明显范围变化、真实调用/预算/付费、凭据、正式发布或影响交付/维护/用户使用的重要选择，先解释具体场景和必要概念；一次2–4题，每题2–3个清楚选项，推荐并说明理由、代价及工期/功能/维护影响。必要明确选择收到后才做依赖工作，沉默非确认；常规实现细节不重复问。保留既有授权，不从流程授权扩大到新业务/真实用量/发布。

**每轮核对与交接**：先读任务memory当前有效规则、适用AGENTS、根README/plan/journal最近周与有关确认；Architecture/技术手册按需。核对代码、分支/HEAD、git状态/近期提交/远端、CI/部署、worktree/并行范围，未知标未知，不覆盖他人修改，文档也同样核查。每个有意义增量及完成/暂停/受阻，在journal当前周日期记目标/理由、实际改动、命令/环境/结果、未验证原因、完整SHA/push、演示、风险/下一步和必要决策。仅必要时更新plan，不复制整份计划。

**Git与真实记录**：只暂存本次具体路径，检查后按独立价值提交与普通推送；核对当时分支/远程，不擅切main、强推/reset/清理用户文件，不整体暂存材料/凭据/产物。未运行/完成/推送不能标完成，失败和修复保留。最终交接提交自身SHA会自引用，因此journal记已存在提交收据，当前交接自身完整SHA/push/最终CI先记聊天与memory，下轮归档，不反复生成补SHA提交。

**每日主线说明（10-22用户要求加深）**：最终回复在当轮聊天充分展开，先明确当天主任务、完成子项和未完成部分，再用具体场景解释修改前问题、为何现在处理、用户可见的变化。沿真实请求/数据链说明核心模块、数据位置、状态变化和关键防错机制，必要概念先用白话解释，再给少量代码入口或小图。验证要说明具体检查行为、实际结果、失败/修复、能证明什么及仍不能证明什么；区分本地/远端、替身/真实模型、构建/部署。交代阶段改善、剩余风险/依赖、下一步及待决，不用几句摘要、文件/命令/数字或链接代替复盘。约10–15分钟理解主线，随复杂度充分展开而不机械凑字数；没有新增业务就直说。链接plan/journal与必要手册，报告完整SHA/push/CI；理解题可选、不作推进前置，必要新决定继续interview。
